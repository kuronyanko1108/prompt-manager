# UI/UX向上計画（フェーズ1拡張）

## やること(優先度 大)

1. 入力欄に自動フォーカス

- タイトルをフォーカスする
- 対象画面は「新規作成画面」「編集画面」
- タイミングは画面遷移表示直後のみ

2. スナックバーを統一

- 色コードを固定　成功：緑系／失敗：赤系
- 表示時間：2000ms
- 文言トーン統一（「～しました」「～に失敗しました」）

3. 保存ボタンの無効化

- 対象「新規作成画面」「編集画面」
- タイトルと本文のいずれかが未入力の時
- 有効のタイミング：タイトルおよび本文に値が設定されたタイミング（リアルタイム）

4. 一覧表示画面のコピーボタン押下時にハイライトをつける機能

- ハイライトは500ms光らせる
- 枠線を青くする
- 連打時はハイライトを再適用し 終了タイミングを最後のクリックから500msに延長する
- 別行クリック時はハイライト対象を即時切り替える
- コピー処理は全クリックで実行する

5. 空状態（0件）のとき一覧画面に表示

- 「まだプロンプトがありません」と表示する
- ボタン配置: 「新規作成」ボタンだけ表示
- デザイン：中央寄せ、余白あり（具体的な数値は実装しながら検討）

## やりたいこと（優先度 中）

1. 一覧の情報量を増やす タイトル＋本文の一部を表示

- 本文表示は50文字
- 改行は許容しない
- 末尾に...をつける

2. エラー時のフォーカス制御

- 複数エラーの時は、最初のエラーメッセージを対象にフォーカスする
- フォーカス移動⇒スナックバーの表示順序
