# バリデーション仕様書

## 1. 目的

本ドキュメントは、ユーザー入力に対するバリデーションルールを定義することを目的とする。  
不正なデータの登録を防ぎ、アプリケーションの品質を担保する。

---

## 2. 対象画面

- 新規作成画面
- 編集画面

---

## 3. 対象項目一覧

| 項目名            | 必須 | 備考 |
| ----------------- | ---- | ---- |
| タイトル（title） | ○    |      |
| 本文（content）   | ○    |      |

---

## 4. バリデーションルール詳細

### 4.1 タイトル（title）

| No  | チェック内容 | 条件                                                                       | エラーメッセージ                        |
| --- | ------------ | -------------------------------------------------------------------------- | --------------------------------------- |
| 1   | 必須チェック | 空文字・NULL不可                                                           | タイトルは必須です                      |
| 2   | 文字数上限   | len関数基準で100文字以内                                                   | タイトルは100文字以内で入力してください |
| 3   | 前後空白除去 | 半角スペース、改行、タブのtrim後の値で必須・文字数判定し、その値を保存する | -                                       |

---

### 4.2 本文（content）

| No  | チェック内容 | 条件                                                                       | エラーメッセージ                      |
| --- | ------------ | -------------------------------------------------------------------------- | ------------------------------------- |
| 1   | 必須チェック | 空文字・NULL不可                                                           | 本文は必須です                        |
| 2   | 文字数上限   | len関数基準で10000文字以内                                                 | 本文は10000文字以内で入力してください |
| 3   | 前後空白除去 | 半角スペース、改行、タブのtrim後の値で必須・文字数判定し、その値を保存する | -                                     |

---

## 4.3 ID（更新時のみ）

※本項目は「編集画面（更新処理）」の場合のみ適用する

| No  | チェック内容   | 条件             | エラーメッセージ               |
| --- | -------------- | ---------------- | ------------------------------ |
| 1   | 必須チェック   | NULL不可         | IDは必須です                   |
| 2   | 数値チェック   | 整数であること   | IDは数値である必要があります   |
| 3   | 値範囲チェック | 1以上であること  | IDは1以上である必要があります  |
| 4   | 存在チェック   | DBに存在すること | 指定されたデータが存在しません |

---

## 5. バリデーション実行タイミング

保存ボタン押下時にバリデーションを実施する

- 新規作成：title / content のみチェック
- 更新時：title / content / id をチェック

---

## 6. エラーハンドリング

| 項目           | 内容                                                                         |
| -------------- | ---------------------------------------------------------------------------- |
| エラー通知方法 | スナックバーで表示                                                           |
| 複数エラー時   | 先頭1件のみ表示                                                              |
| 返却形式       | エラー内容を文字列配列で返却する（将来的に項目単位でのエラー管理を検討する） |

---

## 7. バリデーション責務

| レイヤー   | 役割                                                   |
| ---------- | ------------------------------------------------------ |
| UI         | 入力値の取得                                           |
| Controller | 入力整形・基本バリデーション（形式チェック）           |
| Service    | 最終バリデーション（DBアクセスを伴う存在チェック含む） |

---

## 8. 補足

- 更新処理時は必ずIDをキーとして対象データを特定する
- 存在しないIDが指定された場合は更新を行わない
- IDの存在チェックはService層で実施する
- UIからIDは直接編集させない（hiddenまたは内部保持）
- バリデーションエラー時はDB処理を行わない
- エラー時は画面遷移せず入力内容を保持する
