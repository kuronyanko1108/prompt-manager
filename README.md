# Prompt Manager

## 概要

Prompt Manager は、ChatGPTやGeminiなどの生成AIで利用するプロンプトを管理するためのデスクトップアプリケーションです。

日々利用するプロンプトを保存・分類し、必要なときにすぐ再利用できるようにすることを目的として開発しました。

## 開発目的

生成AIを活用する機会が増える中で、以下の課題を解決するために作成しました。

- よく使うプロンプトを整理したい
- 過去に作成したプロンプトを再利用したい
- 用途ごとにプロンプトを分類したい

## 主な機能

### プロンプト管理

- プロンプトの登録
- プロンプト内容の編集
- プロンプトの削除
- 登録済みプロンプトの確認

### タグ管理

- プロンプトへのタグ付与
- タグによる分類管理
- 複数タグによる整理

### データ保存

- SQLiteによるデータ永続化
- プロンプトとタグの関連管理

| 分類 | 技術 |

## データベース設計

### prompts

プロンプト情報を管理します。

| カラム | 内容 |
| --- | --- |
| id | プロンプトID |
| title | タイトル |
| content | プロンプト本文 |
| created_at | 作成日時 |

### prompt_tags

タグ情報を管理します。

| カラム | 内容 |
| --- | --- |
| id | タグID |
| name | タグ名 |

### prompt_tag_map

プロンプトとタグの関連を管理します。

| カラム | 内容 |
| --- | --- |
| prompt_id | プロンプトID |
| tag_id | タグID |

## 起動方法

```bash
git clone https://github.com/kuronyanko1108/prompt-manager.git
cd prompt-manager

pip install -r requirements.txt

python main.py
```
